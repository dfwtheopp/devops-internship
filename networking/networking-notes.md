# Networking Notes

## Host
A host is a device that can send or receive network traffic.

## IP Address
An IP address identifies a device or network interface on a network.

## Port
A port identifies a particular service or application running on a host.

## DNS
DNS converts domain names such as example.com into IP addresses.

## TCP
TCP is connection-oriented and provides reliable delivery of data.

## UDP
UDP is connectionless and does not guarantee delivery, but it is generally faster than TCP.

## HTTP and HTTPS
HTTP is a protocol used for communication between web clients and servers.
HTTPS is the secure version of HTTP.

## Default Gateway
The default gateway is usually the router a device uses to communicate with networks outside its local network.

## Localhost
Localhost refers to the local computer.
The common IPv4 address for localhost is 127.0.0.1.

## Networking in Docker and AWS
Docker and AWS use networking concepts such as IP addresses, ports, DNS, routing, and security controls.
